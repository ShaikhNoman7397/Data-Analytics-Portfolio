# 📊 Employee Sales Analytics System

A beginner-friendly Python project that analyzes employee sales data using a menu-driven console application.

This project demonstrates Python fundamentals such as dictionaries, functions, loops, conditional statements, searching, sorting, and reusable code while generating simple sales analytics reports.

## 🚀 Features

- View employee records
- Calculate total and average sales
- Find highest and lowest sales performers
- Display top 3 sales employees
- Department-wise sales analytics
- Search employee by ID or Name
- Employee performance rating
- Complete sales report
- Menu-driven console interface

## 🛠️ Technologies

- Python 3
- VS Code / Jupyter Notebook

## 📚 Concepts Used

- Functions
- Loops
- Nested Dictionaries
- Conditional Statements
- Sorting (`sorted`)
- Lambda Functions
- User Input
- Code Reusability
