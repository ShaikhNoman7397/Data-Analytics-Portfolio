## 📖 About the Project

The **Employee Sales Analytics System** is a Python-based console application designed to analyze and manage employee sales performance through a simple menu-driven interface. The system provides useful insights such as total and average sales, top performers, department-wise analytics, employee search, performance ratings, and complete sales reports.

This project was developed to strengthen my understanding of **Python programming** by applying concepts like **functions, loops, nested dictionaries, conditional statements, sorting, user input handling, and code reusability** in a real-world business scenario. It reflects my ability to write organized, modular, and beginner-friendly Python code while solving practical data analysis problems.
